## Featured work

### [Ensemble — Outfit-Aware Fashion Recommender](https://github.com/yilalalalala/ensemble-outfit-recommender)

An end-to-end fashion recommendation system combining personalized retrieval and ranking, outfit
completion, visual search, and a grounded shopping assistant. Built with LightGBM, PyTorch,
FashionCLIP, FastAPI, temporal evaluation, and an [interactive public demo](https://yilalalalala.github.io/ensemble-outfit-recommender/).

### [Blood-Brain Barrier Permeability Prediction](https://github.com/yilalalalala/BBBP-ML-Project)

An NYU team project comparing molecular fingerprints and graph representations across classical ML, neural-network, and GCN models. My contributions include multi-seed fingerprint experiments, class-imbalance handling, and cross-model result visualization; the fork preserves the complete team history and attribution.

### [Transformer Collapse Lab](https://github.com/yilalalalala/transformer-collapse-lab)

A reproducible toolkit for studying representation geometry across transformer layers using controlled prompts, public Hugging Face models, and multiple complementary collapse diagnostics.
